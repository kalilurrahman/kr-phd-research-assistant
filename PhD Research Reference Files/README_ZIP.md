## 🚨 Troubleshooting

**JSON won't load?**
→ Check file paths, ensure CORS enabled if cross-domain, check browser console

**Data not displaying?**
→ Verify JSON structure, check filter logic, test in browser DevTools

**Slow performance?**
→ Gzip compress files, use lazy loading for tabs, implement caching

**Can't import CSV?**
→ Ensure CSV file is properly formatted, check column headers
