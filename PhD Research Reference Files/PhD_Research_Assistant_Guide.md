### Qualitative Methodologies

| Methodology | Description | Key Steps | Common Tools | Disciplines |
|-------------|-------------|-----------|--------------|-------------|
| **Grounded Theory** | Theory development from data | Open, axial, selective coding | NVivo, MAXQDA | Sociology, nursing |
| **Phenomenology** | Study of lived experiences | Bracketing, thematic analysis | NVivo, MAXQDA | Philosophy, psychology |
| **Ethnography** | Study of cultures | Participant observation, field notes | ATLAS.ti, NVivo | Anthropology, sociology |
| **Case Study** | In-depth case investigation | Case selection, within/cross-case analysis | NVivo, Dedoose | Business, education |

### Quantitative Methodologies

| Methodology | Description | Key Steps | Common Tools | Disciplines |
|-------------|-------------|-----------|--------------|-------------|
| **RCT** | Randomized controlled trial | Randomization, intervention, blinding | REDCap, statistical software | Medicine, psychology |
| **Longitudinal Study** | Repeated observations over time | Cohort selection, repeated measures | Statistical software | Epidemiology, development |
| **Cross-Sectional** | Snapshot at single timepoint | Sampling, data collection, analysis | Survey tools, SPSS, R | Public health, sociology |

### Literature Review Methods

| Methodology | Description | Key Steps | Common Tools | Purpose |
|-------------|-------------|-----------|--------------|---------|
| **Systematic Review** | Structured literature search | Protocol, search, screening, synthesis | Covidence, Rayyan | Evidence synthesis |
| **Meta-Analysis** | Statistical combination of results | Effect size calculation, heterogeneity | R, RevMan | Quantitative synthesis |
| **Scoping Review** | Map available evidence | Question formulation, charting | Covidence, Excel | Broad topic overview |

### Mixed Methods

| Approach | Description | Integration Point | Best For |
|----------|-------------|-------------------|----------|

| **Explanatory Sequential** | Quantitative → Qualitative | Follow-up | Explain quant results |
| **Exploratory Sequential** | Qualitative → Quantitative | Development | Build on qual findings |

## Research Workflow Stages

### Stage 1: Research Planning
**Key Activities:** Literature review, research questions, methodology selection, timeline  
**Tools:** Notion, Asana, Trello, mind mapping tools  
**Deliverables:** Research proposal, protocol, timeline  
**Common Challenges:** Scope creep, unrealistic timelines

### Stage 2: Ethics & Compliance
**Key Activities:** IRB submission, consent forms, data security planning  
**Tools:** Cayuse, institutional IRB systems, CITI training  
**Deliverables:** IRB approval, consent forms, ethics certificate  
**Common Challenges:** Lengthy approval process, protocol revisions

### Stage 3: Literature Review
**Key Activities:** Database searching, screening, synthesis, gap identification  
**Tools:** PubMed, Scopus, Zotero, Covidence, Connected Papers  
**Deliverables:** Literature review chapter, synthesis tables  
**Common Challenges:** Information overload, keeping current

### Stage 4: Data Collection
**Key Activities:** Surveys, interviews, experiments, observations  
**Tools:** Qualtrics, REDCap, Zoom, recording equipment  
**Deliverables:** Raw data, field notes, recordings  
**Common Challenges:** Participant recruitment, data quality

### Stage 5: Data Management
**Key Activities:** Data cleaning, organization, backup, version control  
**Tools:** R, Python, Excel, OSF, GitHub  
**Deliverables:** Clean datasets, data dictionary, codebook  
**Common Challenges:** Data security, missing data

### Stage 6: Data Analysis
**Key Activities:** Statistical analysis, coding, thematic analysis, visualization  
**Tools:** R, SPSS, NVivo, MAXQDA, Python  
**Deliverables:** Analysis outputs, figures, themes  
**Common Challenges:** Method selection, software learning curve

### Stage 7: Writing & Reporting
**Key Activities:** Manuscript drafting, revisions, citation management  
**Tools:** Scrivener, Word, Overleaf, Zotero, Grammarly  
**Deliverables:** Manuscript, thesis chapters, reports  
**Common Challenges:** Writer's block, structure, clarity

### Stage 8: Peer Review
**Key Activities:** Journal submission, responding to reviewers, revisions  
**Tools:** Journal submission systems, Overleaf, track changes  
**Deliverables:** Revised manuscript, response letter  
**Common Challenges:** Rejection, critical feedback

### Stage 9: Publication
**Key Activities:** Final submission, proofs, open access decisions  
**Tools:** Publisher platforms, ORCID  
**Deliverables:** Published paper, DOI  
**Common Challenges:** Publication fees, copyright

### Stage 10: Dissemination
**Key Activities:** Conference presentations, social media, data sharing  
**Tools:** Zenodo, OSF, ResearchGate, conference platforms  
**Deliverables:** Presentations, datasets, preprints  
**Common Challenges:** Impact measurement, reach

## Tips for Tool Selection

### 1. Start with Free Trials
Most paid tools offer 7-30 day trials. Test before committing.

### 2. Check Institutional Access
Your university may provide free access to:
- SPSS, Stata, SAS
- NVivo, MAXQDA
- Qualtrics, REDCap
- Scopus, Web of Science

### 3. Consider Learning Curve
Balance features vs. time investment:
- **High learning curve:** R, Python, NVivo, LaTeX
- **Medium learning curve:** MAXQDA, Scrivener
- **Low learning curve:** SPSS, SurveyMonkey, Notion

### 4. Think Long-Term
Choose tools that:
- Support collaboration
- Allow data export
- Have active communities
- Receive regular updates

### 5. Integration Matters
Ensure tools work together:
- Reference managers → Word/Overleaf
- Statistical software → Data repositories
- Project management → Communication tools
